# Dhwani

This repo houses the completed version of our project for SIH, "Dhwani" which won the internal selection round in our college [PS: SIH1714](https://qasih.mic.gov.in/sih2024PS).

## Description

Dhwani is an application designed to streamline interactions between supervisors and the therapists under their guidance, as well as to facilitate their engagements with incoming speech-impaired patients and the consultations managed among them.

## Stack

- Next.js (client)
- Nest.js (server)
